# Scrap — Landing Page

Landing page standalone (Next.js) para deploy em subdomínio próprio.

## Desenvolvimento

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

## Conteúdo

Edite `lib/content.ts` e as imagens em `/public`.

## Deploy

Conecte este repositório na Vercel e configure o subdomínio desejado.
